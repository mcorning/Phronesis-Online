# Operating Principle

The Frontiers page exists to allocate attention, not to store project details.

Status updates should remain concise:

- objective
    
- recent progress
    
- immediate next action
    
- current status
    

Detailed work belongs inside the corresponding project.

---

# Organizational Grammar

Every frontier follows the same recursive structure.

```
Frontiers
    Projects
        Systems
            Workflows
                Tasks
```

This topology is recursive.

Each project can contain its own systems.

Each system can contain its own workflows.

Each workflow can contain its own tasks.

The organizational grammar remains the same regardless of scale.

This consistency allows the entire body of work to grow as a coherent holarchy rather than a collection of unrelated projects.
